# SMART EDU 365

منصة تعليمية عربية مبدئية للفئة العمرية 5–15 سنة.

## الأقسام المعتمدة
1. **أتعلّم:** اللغة الإنجليزية والرياضيات.
2. **أرتقي:** الأخلاق والقيم والسلوك الإيجابي وفن التعامل مع الناس.
3. **أكتشف:** التفكير والإبداع وحل المشكلات والمهارات الحياتية.

## المراحل العمرية
- 5–7 سنوات: تعلم بصري، قصص قصيرة، أصوات وأنشطة بسيطة.
- 8–11 سنة: تأسيس المهارات، تمارين متدرجة، تعاون وحوار.
- 12–15 سنة: تطبيقات عملية، تفكير نقدي، تواصل ومسؤولية.

## مبادئ السلامة
- لا محادثات مفتوحة غير مراقبة للأطفال.
- لا جمع لبيانات شخصية غير ضرورية.
- إشراف ولي الأمر وإعدادات مناسبة للعمر.
- المحتوى الأخلاقي تعليمي وغير مهين، ويحترم اختلاف الناس.
- لا إعلانات موجهة للأطفال.
